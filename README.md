# دفتر الأقساط

تطبيق ويب لإدارة العملاء وعقود الأقساط والمهلة والسداد والتقارير السنوية. يعمل على الجوال والآيباد والكمبيوتر، وبياناته في قاعدة PostgreSQL على Supabase.

## الملفات

| الملف | وظيفته |
| --- | --- |
| `index.html` | التطبيق كاملًا: الواجهة والمنطق |
| `config.js` | رابط مشروع Supabase والمفتاح العام |
| `vendor/supabase.js` | مكتبة Supabase للمتصفح |
| `supabase/schema.sql` | جداول قاعدة البيانات وصلاحياتها |
| `manifest.webmanifest` و `icons/` | تثبيت التطبيق على الشاشة الرئيسية |

## التشغيل على GitHub Pages

1. ارفع كل الملفات إلى مستودع على GitHub.
2. من المستودع: Settings ثم Pages، اختر الفرع `main` والمجلد `/ (root)` واحفظ.
3. بعد دقيقة يظهر رابط التطبيق بصيغة `https://USERNAME.github.io/REPO/`.
4. في Supabase: Authentication ثم URL Configuration، ضع هذا الرابط في Site URL وأضفه إلى Redirect URLs.

## الحسابات

- من صفحة الدخول يستطيع أي شخص إنشاء حساب ببريده، ويصله رابط تأكيد قبل أول دخول.
- لكل حساب دفتره الخاص: عملاؤه وعقوده ومدفوعاته لا يراها ولا يعدّلها أي حساب آخر. هذا مفروض في قاعدة البيانات نفسها (Row Level Security) لا في الواجهة فقط.
- من تبويب «الحساب» يغيّر المستخدم اسمه وبريده وكلمة مروره.
- «نسيت كلمة المرور» في صفحة الدخول يرسل رابطًا لاختيار كلمة مرور جديدة.
- لإيقاف إنشاء الحسابات الجديدة: في Supabase من Authentication ثم Sign In / Providers أوقف خيار السماح بالتسجيل الجديد.

رسائل التأكيد والاستعادة تُرسل من بريد Supabase الافتراضي، وعدد رسائله في الساعة محدود. عند كثرة المستخدمين اربط خدمة بريد خاصة (SMTP) من إعدادات Authentication.

## إعادة إنشاء قاعدة البيانات

في مشروع Supabase جديد، انسخ محتوى `supabase/schema.sql` إلى SQL Editor ونفّذه، ثم ضع رابط المشروع والمفتاح العام (publishable) في `config.js`.

## طريقة الحساب

- الربح: يُحتسب عند التحصيل. من كل دفعة يُؤخذ نصيبها من الزيادة على المبلغ المسلَّم، في سنة تاريخ الدفعة.
- الخسارة: المتبقي غير المسدَّد × (المبلغ المسلَّم ÷ إجمالي السداد)، للعقود المسجَّلة ديونًا معدومة فقط.
- رأس المال: مجموع المبالغ المسلَّمة في كل العقود.
- الزكاة: (رأس المال + الأرباح منذ البداية − الخسائر منذ البداية) × النسبة. الرقم تقديري ويُراجع مع مختص.
